# Протокол Стикеля над кольцом циклических многочленов

## Описание проекта

Данный проект реализует **криптографический протокол Стикеля** для выработки общего секретного ключа между двумя сторонами (Алисой и Бобом). В качестве алгебраической основы используется кольцо **циклических многочленов**  
\[
R = \mathbb{Z}_n[x]/(x^{N+1}-1),
\]
где коэффициенты многочленов берутся по модулю \(n\), а умножение мономов происходит по правилу \(x^i \cdot x^j = x^{(i+j) \bmod (N+1)}\).

Протокол работает с квадратными матрицами над этим кольцом. Публичными параметрами служат две некоммутирующие матрицы \(A\) и \(B\). Алиса выбирает секретные натуральные числа \(n, m\) и отправляет Бобу \(u = A^n B^m\). Боб выбирает секретные \(r, s\) и отправляет Алисе \(v = A^r B^s\). Затем каждая сторона вычисляет общий ключ:

- Алиса: \(K_A = A^n v B^m\)
- Боб: \(K_B = A^r u B^s\)

В силу коммутации \(A\) и \(B\) с самими собой и перестановочности степеней, ключи совпадают: \(K_A = K_B\).

Интерфейс реализован с помощью **Streamlit**, что позволяет наглядно наблюдать каждый шаг протокола, видеть сгенерированные матрицы и полученные ключи в формате LaTeX.

## Структура проекта

- `app.py` — основной файл с веб-интерфейсом Streamlit.
- `CyclicPolynomial.py` — класс, реализующий циклический многочлен с операциями сложения, умножения, возведения в степень.
- `protocol.py` — реализация протокола Стикеля (генерация матриц, шаги Алисы и Боба, вычисление ключей).
- `utils.py` — вспомогательные функции: создание единичной матрицы из многочленов, возведение матрицы в степень, проверка на единичность.
- `requirements.txt` — зависимости проекта.

## Требования

- Python 3.8 или выше
- Установленные библиотеки:
  - `streamlit`
  - `numpy`

## Установка и запуск

1. Клонируйте репозиторий или скачайте файлы проекта.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Запустите приложение:

```bash
streamlit run app.py
```

4. В браузере откроется интерфейс, где можно задать параметры (модуль кольца, максимальную степень многочлена, размер матриц, плотность ненулевых коэффициентов) и сгенерировать сеанс протокола.

## Пример работы

После нажатия кнопки **«Сгенерировать и запустить протокол»** приложение:

- Генерирует две случайные некоммутирующие матрицы \(A\) и \(B\).
- Алиса и Боб выбирают случайные секретные степени.
- Отображаются промежуточные матрицы \(u\), \(v\) и итоговые ключи \(K_A\), \(K_B\).
- Выводится сообщение о совпадении ключей.

Все матрицы визуализируются в формате LaTeX, что удобно для анализа.

## Математические детали

- **Циклический многочлен** — многочлен степени не выше \(N\), где умножение мономов циклически сдвигает степень по модулю \(N+1\). Такой подход эквивалентен работе в групповом кольце \(\mathbb{Z}_n[C_{N+1}]\).
- **Свойства протокола** — стойкость основана на трудности извлечения корней из матриц и проблемы поиска коммутирующих элементов в некоммутативной полугруппе матриц.
- Выбор параметров: для демонстрации используются небольшие значения \(n\), \(N\) и размера матриц (2…4). В реальных криптографических приложениях параметры должны быть значительно больше.

## Возможные улучшения

- Добавление проверки порядка матриц для ускорения (использование порядка вместо фиксированной верхней границы).
